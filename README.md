# 🎓 Klassens Grill- och Spelträff Survey

A bilingual (Swedish/English) survey for planning a class BBQ and games event.

## 📋 Pages

- **Survey Form**: https://nastehomah23-ship-it.github.io/grill-sp/
- **Admin Response Viewer**: https://nastehomah23-ship-it.github.io/grill-sp/responses-viewer.html

## 🎯 How It Works

1. **Users fill out the survey** with:
   - Preferred dates
   - Food restrictions/allergies
   - Location suggestions
   - Email address

2. **Responses are saved locally** in browser localStorage

3. **View all responses** in the admin panel:
   - Table of all responses
   - Statistics on popular dates and locations
   - Export to CSV

## 📊 Admin Panel Features

- 📈 See total response count
- 🗓️ View most popular dates
- 📍 View location suggestions
- 📥 Export responses to CSV
- 🔄 Auto-refreshes every 10 seconds

## 🔧 Development

Files:
